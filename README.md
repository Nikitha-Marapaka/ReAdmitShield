# 🏥 ReAdmitShield: 30-Day Readmission Prevention Dashboard

ReAdmitShield helps visualize and predict hospital readmission risks using simulated EHR data and a trained AI model.

### 🚀 Live Demo
👉 [Launch the App on Streamlit](https://readmitshield-iywkykfbqkxgkocvmes8ev.streamlit.app/)

### 🧠 Features
- Predicts 30-day readmission risk using simulated hospital EHR data.
- Interactive dashboard built with Streamlit.
- Machine learning model trained with .
- Clean UI for patient-level predictions.

### 🧩 Tech Stack
- Python
- Streamlit
- Pandas / Scikit-learn
- Matplotlib / Plotly (if applicable)

### 🧾 How to Run Locally
1. Clone the repository  
   ```bash
   git clone https://github.com/Nikitha-Marapaka/ReAdmitShield.git
   cd ReAdmitShield
   ```

2. Create & activate a virtual environment  
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

3. Install dependencies  
   ```bash
   pip install -r requirements.txt
   ```

4. Run the app  
   ```bash
   streamlit run app.py
   ```
